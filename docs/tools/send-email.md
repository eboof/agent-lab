📧 Send Email Tool Guide

Overview

The Send Email Tool provides a standard way for agents to send emails through a configured SMTP service.
It’s useful for notifications, daily reports, or agent-driven communication.

The tool wraps Nodemailer, with environment variables for SMTP credentials stored in .env.

⸻

Input Parameters

Name	Type	Required	Description
to	string	✅	Recipient email address (comma-separated list supported)
subject	string	✅	Subject line of the email
body	string	✅	The plain-text body of the email
html	string	❌	Optional HTML version of the email body (takes priority if provided)
from	string	❌	Custom “from” address. Defaults to SMTP configured address if omitted.
cc	string	❌	Comma-separated CC addresses
bcc	string	❌	Comma-separated BCC addresses
attachments	array	❌	List of file paths or buffers to attach (optional)


⸻

Output Schema

Returns JSON with the result of sending:

{
  "accepted": ["recipient@example.com"],
  "rejected": [],
  "messageId": "<unique-message-id@example.com>",
  "response": "250 OK: queued as 12345"
}


⸻

Example Usage

Example 1: Simple Email

Input

{
  "to": "user@example.com",
  "subject": "Hello from Agent-Lab",
  "body": "This is a test email sent by an Agent!"
}

Output

{
  "accepted": ["user@example.com"],
  "rejected": [],
  "messageId": "<abc123@example.com>",
  "response": "250 OK: queued as 12345"
}


⸻

Example 2: Email with HTML + CC

Input

{
  "to": "main@example.com",
  "cc": "team@example.com",
  "subject": "Daily Report",
  "body": "Plain-text fallback",
  "html": "<h1>Daily Report</h1><p>Generated by Agent-Lab.</p>"
}


⸻

Error Cases
	•	Missing required fields (to, subject, body) → 400 Bad Request
	•	SMTP misconfigured → Error: Invalid login or connection timeout
	•	Recipient rejected → {"rejected": ["badaddress@example.com"]}

⸻

Setup Notes
	•	SMTP config is read from .env:

SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=myuser
SMTP_PASS=supersecret
SMTP_FROM=agent@agentlab.local

	•	If from param is omitted, tool defaults to SMTP_FROM.
	•	Ensure .env is present at repo root before using the tool.
