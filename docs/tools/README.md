## Quick Start

1. **Browse Available Tools**: Check the individual tool docs above for parameters and usage
2. **Test in Playground**: Use the Tools tab in Agent-Lab UI to test tools interactively  
3. **Use in Agents**: Select tools when building agents to enable specific capabilities
4. **Create Custom Tools**: Follow the Tool Development Guide to build your own

## Tool Categories

- **🌐 API Integrations**: External API connectors and data fetchers
- **📊 Data Processing**: Tools for transforming and analyzing data  
- **📧 Communication**: Email, messaging, and notification tools
- **📥 Gmail Tools**: Complete Gmail integration suite (read, send, manage)
- **🌍 Web Tools**: Scraping, fetching, and web interactions
- **⚙️ System Tools**: File operations, CLI commands, and utilities
